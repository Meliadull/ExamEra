# ExamEra

Веб-платформа электронного тестирования и анализа знаний учащихся (по ТЗ из `_docs/Техническое задание.txt`).

**Цикл:** создание теста → назначение → электронное прохождение → автоматическая проверка → результаты → аналитика → отчётность → аудит.

## Стек

| Часть | Технологии |
| --- | --- |
| Backend | Node.js 22.13+ (рекомендуется 24), Express 5, TypeScript, Zod |
| База данных | SQLite (встроенный `node:sqlite`, без внешних сервисов). Схема — в `server/src/db.ts`, совместима с переносом на PostgreSQL |
| Frontend | React 19, TypeScript, Vite, React Router, Recharts, KaTeX (формулы) |
| Excel | ExcelJS (импорт тестов, экспорт отчётов) |

## Быстрый старт

```bash
npm run setup     # установка зависимостей (корень, server, client)
npm run dev       # API на :4000 + интерфейс на http://localhost:5173
```

При первом запуске пустая БД заполняется демо-данными. Пересоздать демо-базу: `npm run seed`.

### Production

```bash
npm run build
NODE_ENV=production npm start   # API и собранный интерфейс на одном порту (API_PORT или PORT, по умолчанию 4000)
```

Настройки — в `server/.env` (образец: `server/.env.example`):

- `GOOGLE_CLIENT_ID` — OAuth Client ID (Web application) из Google Cloud Console; без него кнопка Google неактивна.
- `SMS_PROVIDER=console` — OTP-коды печатаются в консоль и показываются в интерфейсе. **Только для разработки.** Для боевого режима подключите SMS-шлюз в `server/src/services/otp.ts` (`sendSms`).
- `COOKIE_SECURE=true` — за HTTPS; `TRUST_PROXY=true` — за nginx (корректный IP в аудите).

## Что реализовано (MVP по п. 47 ТЗ)

- **Регистрация по телефону с OTP**, вход по телефону/email и паролю, **вход через Google**, «Запомнить меня», восстановление доступа по SMS, выход; контроль активных сеансов, смена пароля с завершением других сеансов.
- **Самостоятельная регистрация**: аккаунты создают только сами пользователи (телефон или Google); при регистрации можно указать «Я преподаватель» — это заявка, а не роль. Администратор не вводит телефон, email и пароль: он выбирает зарегистрированного пользователя и назначает роль и обязанности (учителю — предметы и закреплённые группы, ученику — группу).
- **4 роли** (ученик, учитель, администратор, аудитор). Предметы и группы учителю назначает только администратор; учитель создаёт тесты только по своим предметам. Классный руководитель видит полную аналитику своего класса (все предметы и преподаватели); другим группам учитель может назначать тесты, но их аналитику видит только по своим тестам. Раздел «Мой класс» в меню учителя — контроль своего класса: кто требует внимания (низкий результат, пропущенные и несданные тесты), успеваемость каждого учащегося и выполнение всех тестов, назначенных классу. Права проверяются **на сервере** для каждого запроса и ограничиваются областью доступа (учитель видит только свои тесты и свои группы). Аудитор — строго только чтение (запрет записи на уровне middleware).
- **Группы, предметы (с темами), учебные периоды**.
- **Конструктор тестов** в 5 шагов (Основное → Вопросы → Настройки → Назначение → Публикация): 5 типов вопросов (один ответ, несколько, да/нет, верно/неверно, короткий ответ), формулы LaTeX (`$…$`), таблицы, изображения, баллы, пояснения. Статусы: черновик / опубликован / завершён / архив; копирование.
- **Импорт из XLSX** по шаблону ТЗ: проверка структуры и полей, ошибки по строкам, предпросмотр, импорт после подтверждения.
- **Назначение** группам или отдельным учащимся: сроки, длительность, попытки, проходной балл, показ результата и правильных ответов.
- **Прохождение**: таймер (по серверному времени), навигация по вопросам, отметки, автосохранение (при выборе ответа, переходах и каждые 15 с, плюс резервная копия в браузере при потере связи), предупреждение перед завершением, автозавершение по времени и по сроку (фоновая задача на сервере). Перемешивание вопросов и вариантов.
- **Автопроверка** (строгая или частичная оценка для нескольких ответов), сохранение правильных/неправильных/пропущенных, баллов, процента, времени.
- **Аналитика**: по тесту (участники, распределение, анализ каждого вопроса с распределением вариантов), по группе (рейтинг, сложные вопросы), по учащемуся (динамика, слабые темы), общая с фильтрами и сравнением с прошлым периодом.
- **Отчёты и экспорт XLSX/CSV**: по тесту, группе, ученику, сводный административный, списки результатов и журнала аудита.
- **Журнал аудита**: все критические действия; записи неизменяемы (триггеры БД запрещают UPDATE/DELETE).
- **Уведомления**: назначен тест, остались сутки до окончания, ученик завершил тест, вся группа завершила.
- **Административная панель**: статистика, активность, системные предупреждения, раздел «Пользователи» — учётные записи (контакты, способ входа, статус, блокировка, восстановление доступа, история активности); раздел «Роли» — кто какую роль выполняет (заявки преподавателей, назначение ролей, предметов и групп, фильтры по роли/предмету/группе, матрица прав), матрица прав, настройки.
- **Языки**: русский и узбекский (`client/src/i18n/`); новый язык добавляется одним файлом словаря.
- **Адаптивный интерфейс** (ПК, планшет, смартфон; нижнее меню для учеников на телефоне).

## Безопасность

Пароли — scrypt с солью; сессии — случайные токены в httpOnly-cookie (в БД хранится только хеш); защита от перебора (блокировка после 5 неудачных попыток) и rate limit на авторизацию/OTP; валидация всех входных данных (Zod); заголовки безопасности (Helmet, CSP); загружаемые файлы проверяются по сигнатуре и сохраняются под случайными именами; защита CSV от формульных инъекций; правильные ответы никогда не передаются клиенту во время прохождения.
